Project Title

Diabetes Disease Progression Prediction using Linear Regression

Objective

The objective of this project is to predict the disease progression score of diabetes patients using medical measurements.

This is a Supervised Machine Learning Regression problem because:

Input (X): Medical measurements (features)
Output (y): Disease progression score (continuous numeric value)
